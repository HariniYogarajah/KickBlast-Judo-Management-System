# KickBlast Judo Management System 🥋

## Project Overview

KickBlast Judo Management System is a desktop-based application developed to manage the main activities of a judo training environment.

The system provides features for managing athletes, training plans, weight categories, competitions, private coaching and monthly fee calculations.

The application was successfully developed, run and tested using C# Windows Forms with a SQL Server database.

## Key Features

- Athlete Management
- Training Plan Management
- Weight Category Management
- Competition Management
- Private Coaching Management
- Competition Fee Calculation
- Training Plan Fee Calculation
- Monthly Payment Calculation
- SQL Server Database Integration
- CRUD Operations

## Technologies Used

- C#
- Windows Forms
- .NET
- SQL Server
- SQL Server Management Studio
- Visual Studio

## Database

The system uses SQL Server to store and manage application data.

Main database tables include:

- Athlete
- Admin
- Training_Plan
- Weight_Category
- Competition
- Private_Coaching
- Ath_Competition
- Ath_Pri_Coaching
- MonthlyPay
